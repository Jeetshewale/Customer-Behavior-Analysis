### Prerequisites

- [Python 3.x]
- [pip / conda]

```bash

git clone https://github.com/Jeetshewale/Customer-Behavior-AnalysisAC.git
cd Customer-Behavior-AnalysisAC

# (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```
